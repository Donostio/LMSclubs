# LMS Clubs: forwarding pages (permanent)

LMS Clubs has moved to **https://clubslms.donostio.uk**.

This repository only forwards old links (`donostio.github.io/LMSclubs/...`) to the same page on
the new site, so bookmarks, QR codes and links in old emails keep working.

**Do not delete, rename or make this repository private, and do not put the site back here.**
The site itself is in the private repository `Donostio/ClubsLMS`.

- `index.html`, `whatsnew.html`, `lms_clubs_guide.html`: the old pages.
- `404.html`: any other old address.
All four are the same file. No analytics or cookies run here; forwarded visits are labelled
`utm_source=old_github_link` so the new site's Google Analytics can count them.
